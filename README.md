# NIZEK Investor Hub

I want to build a world-class interactive investor website for NIZEK.

This is NOT a landing page.

This is NOT a marketing website.

This is NOT a traditional pitch deck.

This is an interactive investment platform that combines:

• A premium venture studio website

• A financial model

• An investment simulator

• A private equity style presentation

• An investor decision engine

The goal is for an investor to completely understand the business model, interact with the assumptions, and immediately see how their investment performs under different scenarios.

Think of this project as:

Apple.com

+

BlackRock

+

Sequoia Capital

+

Bloomberg Terminal

The website should feel premium, institutional, sophisticated and minimal.
